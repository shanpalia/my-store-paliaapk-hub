# My Store By PaliaAPK HUB

Responsive general-store website with full-window company selection.

- **Create Company:** saves a basic profile in this browser and opens the main store.
- **Select Company:** selects a profile saved in this browser.
- **Exit:** displays an exit dialog; browsers normally block websites from closing tabs they did not open.
- **Switch company:** returns to company selection.

Files: `index.html`, `styles.css`, `script.js`.

Important: company profiles are saved locally only and do not sync across devices. Product names/prices are sample data. There is no real shared database, admin panel, online payment or persistent order management yet. Set `STORE_WHATSAPP` in `script.js` to enable WhatsApp order requests.

GitHub Pages: repository **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
